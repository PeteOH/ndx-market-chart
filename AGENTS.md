# Repository instructions

1. Create every change on a new branch from the latest `main`.
2. Commit and push completed changes, then open a pull request targeting `main`.
3. Do not merge a pull request unless the project owner explicitly requests it.
4. Keep each pull request focused on one coherent change.
5. Update `README.md` whenever setup, generation, deployment, or operation changes.
6. Commands that download data or generate the chart must support `--verbose`.
